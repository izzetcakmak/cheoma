Core Strengths

why this builder
⚡

Ships MVPs in days, not months

The CHEOMA MVP you can use right now — Solidity contract, test suite, deploy scripts, explorer verification, and a live frontend on GIWA Sepolia — was built and shipped in a single day. That is the working pace, not the exception.

◉

Fully on-chain art & generative specialization

CHEOMA's sumaksae tile art and metadata live 100% inside the contract — no IPFS, no servers, nothing to rot. Hoodlings proved this approach at 4,663-token scale on mainnet.

□

Zero-dependency engineering

Single-file frontends, no frameworks, no build steps, one CDN script (ethers). Fewer moving parts means fewer failures, instant loads, and products that stay online for years without maintenance.

한

EN / TR fluent, learning KO

Building for a Korean-rooted chain with genuine respect for the culture it draws from — giwa-bulsa is treated as a living tradition to honor, not an aesthetic to borrow. Korean-friendly UX is a first-class goal.

Why Solo Works for GASOK

tight loop now, growing roof later

During the MVP Build Phase, one builder is the tightest possible feedback loop. Idea → contract → deploy → user feedback → iteration happens in hours, with zero coordination overhead. Every mentor note from the program lands directly in the hands of the person who writes the code — nothing is lost in translation between roles. The track record above shows this loop already works: six live products, several on mainnet, all built solo.

Solo is the starting point, not the plan. During the program, CHEOMA will actively recruit a Korean community manager / designer — someone who can lead temple and brand collaboration pilots, shape Korean-language community channels, and make sure the giwa-bulsa tradition is represented authentically as the roof grows from one canvas into a multi-roof platform. Like the roof itself: one tile is laid first, then others join until it holds together.
